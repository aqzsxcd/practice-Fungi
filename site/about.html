О проекте

Главная О проекте Участники Журнал Ресурсы

Описание

Fungi - интеллектуальный онлайн-сервис по принципу википедии, посвящённый грибам. Платформа содержит статьи и фотографии различных видов грибов, где пользователи могут изучить информацию о съедобности, ареале и сезонности. Главное отличие - встроенная нейросеть, обученная на загруженных изображениях. Пользователь загружает своё фото гриба, и ИИ предлагает вероятный вариант определения, объединяя теорию с практической идентификацией.

Цель

Цель Fungi - создать доступный инструмент для идентификации грибов по фото, объединив его с краудсорсинговой энциклопедией. Задача проекта - снизить риск ошибок при сборе грибов и популяризировать микологические знания. В перспективе, Fungi стремится сформировать сообщество грибников и микологов, которым ИИ помогает безопасно распознавать грибы в реальной жизни.

Процесс разработки приложения

Разработка приложения Fungi проходит поэтапно. Сначала команда определила основные функции будущего сервиса: просмотр информации о грибах, поиск видов, загрузка изображений и автоматическое распознавание грибов с помощью ИИ. После обсуждения идеи был создан макет интерфейса и выбрана структура сайта.

Далее началась техническая реализация проекта. Для создания страниц использовались HTML и CSS, а для работы с нейросетью изучались библиотеки Python и TensorFlow. В процессе работы участники проекта учились взаимодействовать через GitHub, загружать изменения в репозиторий и объединять результаты совместной работы.

В настоящее время проект продолжает развиваться. Планируется расширение базы данных грибов, улучшение точности распознавания изображений и добавление новых возможностей для пользователей. Также рассматривается идея создания мобильной версии приложения для более удобного использования в лесу или на природе.
