# Журнал проекта Fungi

## Неделя 1 — Формирование идеи проекта

На первой неделе команда обсуждала общую концепцию проекта и определяла его основные задачи. Было принято решение создать веб‑приложение Fungi, которое позволит пользователям изучать информацию о грибах и распознавать их с помощью искусственного интеллекта.

Участники анализировали похожие сервисы, изучали статьи и подбирали подходящие технологии для реализации проекта. Также был составлен первоначальный план разработки и распределены обязанности между членами команды.

---

## Неделя 2 — Исследование предметной области

На данном этапе проводилось изучение различных видов грибов, их классификации, сезонности и особенностей. Команда собирала изображения грибов из открытых источников для дальнейшего обучения модели.

Кроме того, участники изучали основы работы нейронных сетей и методы компьютерного зрения. Были рассмотрены библиотеки TensorFlow и Keras, а также способы обработки изображений.

---

## Неделя 3 — Разработка структуры сайта

В течение недели был создан каркас веб‑сайта, включающий:
- главную страницу;
- раздел «О проекте»;
- журнал разработки;
- страницу участников;
- раздел ресурсов.

Особое внимание уделялось удобству навигации и простому интерфейсу. Команда изучала основы HTML и CSS, подбирала цветовую палитру и оформляла страницы в едином стиле.

---

## Неделя 4 — Работа над нейросетью

Команда начала обучение первой версии модели искусственного интеллекта для распознавания грибов. Для обучения использовались изображения съедобных и несъедобных грибов.

Проводилось тестирование качества распознавания и настройка параметров модели. В процессе разработки возникла проблема недостаточного количества данных, поэтому команда начала искать дополнительные изображения для повышения точности.

---

## Неделя 5 — Тестирование и улучшение проекта

На этой неделе проводилось тестирование сайта и исправление ошибок. Были улучшены:
- оформление страниц;
- структура текста;
- навигация между разделами;
- отображение контента.

Также команда проверяла работу сайта на разных устройствах и в различных браузерах.

---

## Неделя 6 — Работа с GitHub и документацией

Участники проекта активно использовали GitHub для совместной работы. Команда училась:
- создавать коммиты;
- обновлять репозиторий;
- работать с ветками;
- объединять изменения.

Дополнительно была начата работа над документацией проекта и созданием файлов Markdown для раздела docs.

---

## Неделя 7 — Подготовка итоговой версии

На завершающем этапе команда занималась финальным оформлением проекта. Были добавлены дополнительные материалы, расширены описания разделов и улучшен внешний вид сайта.

Также была подготовлена структура проекта для удобного запуска через HTML‑файл и дальнейшей публикации на GitHub Pages.

---

## Итоги работы

В ходе выполнения проекта команда получила опыт:
- разработки веб‑сайтов;
- работы с Git и GitHub;
- использования HTML и CSS;
- изучения основ искусственного интеллекта;
- командной разработки программного обеспечения.

Проект Fungi стал хорошей практикой для изучения современных технологий и совместной работы над приложением.
