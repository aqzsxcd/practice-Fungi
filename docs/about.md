# О проекте Fungi

## Описание проекта

**Fungi** — интеллектуальный онлайн‑сервис по принципу энциклопедии, посвящённый грибам. Платформа содержит статьи, изображения и описания различных видов грибов. Пользователи могут изучать информацию о съедобности, ареале распространения, сезонности и особенностях каждого вида.

Главная особенность проекта — встроенная система распознавания грибов с использованием искусственного интеллекта. Пользователь загружает фотографию гриба, после чего система анализирует изображение и предлагает наиболее вероятный вариант определения вида.

Проект объединяет образовательную платформу и современные технологии компьютерного зрения.

---

## Цель проекта

Цель проекта Fungi — создание доступного и удобного инструмента для идентификации грибов по фотографии.

Основные задачи проекта:

- снижение риска ошибок при сборе грибов;
- популяризация знаний в области микологии;
- создание удобной базы данных грибов;
- внедрение технологий искусственного интеллекта в образовательные сервисы;
- развитие сообщества любителей природы и грибников.

---

## Процесс разработки приложения

### Этап 1. Формирование идеи

На начальном этапе команда обсуждала концепцию будущего проекта и определяла его основные функции. Было решено создать веб‑приложение, которое объединит информационный справочник грибов и систему распознавания изображений.

Участники анализировали существующие сервисы, изучали их преимущества и недостатки, а также составляли список необходимых возможностей будущего приложения.

---

### Этап 2. Проектирование интерфейса

После обсуждения идеи началось проектирование интерфейса сайта. Были созданы первые макеты страниц, определена структура меню и продумана навигация между разделами.

Особое внимание уделялось:
- простоте интерфейса;
- удобству использования;
- читаемости информации;
- единому стилю оформления.

---

### Этап 3. Разработка сайта

Для создания сайта использовались HTML и CSS. Команда занималась:
- созданием структуры страниц;
- настройкой навигации;
- оформлением дизайна;
- подключением изображений и текстового контента.

Также участники проекта изучали основы адаптивной верстки и работу современных веб‑технологий.

---

### Этап 4. Работа с GitHub

Во время разработки команда активно использовала GitHub для хранения проекта и совместной работы. Участники учились:
- создавать репозиторий;
- загружать изменения;
- работать с ветками;
- объединять изменения в общий проект.

Это позволило организовать совместную разработку и отслеживать историю изменений.

---

### Этап 5. Разработка ИИ‑модуля

Для распознавания грибов изучались библиотеки Python и TensorFlow. Команда начала собирать изображения грибов и тестировать первые версии модели искусственного интеллекта.

На этом этапе проводилось:
- обучение нейронной сети;
- обработка изображений;
- тестирование точности распознавания;
- поиск способов улучшения качества модели.

---

### Этап 6. Тестирование проекта

После создания основных страниц сайта команда приступила к тестированию. Проверялась:
- корректность отображения страниц;
- работа навигации;
- удобство интерфейса;
- наличие ошибок в коде.

Были исправлены найденные недочёты и улучшен внешний вид проекта.

---

### Дальнейшее развитие

В дальнейшем планируется:
- расширение базы данных грибов;
- улучшение точности нейросети;
- создание мобильной версии приложения;
- добавление личных кабинетов пользователей;
- возможность сохранения найденных грибов в избранное.

Проект продолжает развиваться и постепенно становится полноценной образовательной платформой.
